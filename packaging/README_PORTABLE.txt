实时语音虚拟患者 - Windows 便携版

运行条件
- Windows 10/11 64 位
- 可访问豆包服务的网络
- 建议使用最新版 Microsoft Edge 或 Google Chrome

使用方法
1. 保持本文件夹内所有文件的相对位置不变。
2. VERSION.txt 记录当前发布版本。
3. 双击 start_ui.cmd。
4. 浏览器打开后，允许使用麦克风。

数据与安全
- 目标电脑不需要安装 Python。
- .env 含有明文 API 凭证，只能将本文件夹复制到受信任的电脑。
- 自定义患者设定保存在 data\patient_templates.json，会随文件夹迁移。
- 会话文字、研究事件及启用后的音频保存在本文件夹下，不会自动上传到 Git。
- 如豆包模型、账号权限或网络环境变化，界面可以启动，但实时语音或 CPAS 服务可能无法连接。
