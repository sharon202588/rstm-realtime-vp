# RSTM-SP 视频视觉素材提示词

这些提示词用于生成或指导制作视频中的概念图、模拟界面和动画素材。所有素材均为虚构演示，不包含真实学习者数据、真实患者数据、真实音频或真实 API 信息。

## 1. 数字人讲解画面

用途：10-25s、结尾段落  

提示词：
> 一位专业、温和的中文医学教育讲解员，站在现代临床沟通训练中心背景中，身旁有半透明数字屏幕，屏幕上显示 RSTM-SP、实时对话、虚拟患者、沟通训练等关键词。画面为 16:9，浅色医学教育风格，蓝绿色主色调，干净可信，不夸张，不商业广告化。

屏幕文字：
- RSTM-SP
- 自适应实时虚拟患者
- 面向医学教育研究

## 2. 诊室与坏消息告知训练场景

用途：0-10s  

提示词：
> 安静、专业的医院诊室概念画面，一位医生坐在桌前准备进行坏消息告知沟通训练，桌上有电脑屏幕，屏幕显示“沟通训练：Breaking Bad News”。画面温和、克制、真实但不出现可识别人物，医学教育演示风格，16:9。

屏幕文字：
- 沟通训练：Breaking Bad News
- 安全练习
- 可重复反馈

## 3. 模拟医生-虚拟患者对话界面

用途：10-25s、60-75s  

提示词：
> 一个干净的医学教育训练软件模拟界面，左侧为医生输入，右侧为虚拟患者回应。对话内容为虚构示例，不包含真实姓名或真实数据。界面上方显示 RSTM-SP，右侧有状态面板显示 Level 3: Concerned / Downcast。现代 SaaS 风格，信息密度适中，16:9。

示例界面文本：
- Doctor: 我们先聊聊您对检查结果的了解。
- Virtual Patient: 我这几天一直有些担心，不知道情况是不是严重。
- Current Style: Level 3 Concerned / Downcast
- Mode: Breaking bad news training

## 4. CPAS 评分卡

用途：25-45s  

提示词：
> 医学沟通训练系统中的结构化评分卡，标题为 CPAS Communication Performance Assessment Score。评分卡包含 Stage、Track A、Track B、Final CPAS、Brief rationale 等字段。内容为模拟数据，强调这是内部控制信号。视觉风格专业、简洁、可读，适合作为教学演示动画。

示例界面文本：
- Stage: Perception
- Track A: +1
- Track B: +1
- Final CPAS: +2
- Brief rationale: 先了解患者认知，并保持支持性语气。

## 5. RSTM 关系状态轨迹曲线

用途：25-60s  

提示词：
> 一个简洁的数据可视化动画画面，展示 RSTM relational state trajectory。纵轴为 S(t)，横轴为 Turn。曲线从 S(t)=-0.25 开始，标记 Level 3 Concerned / Downcast。随着支持性沟通，曲线逐步上升；随着不恰当沟通，另一条虚线下降。医学研究图表风格，清晰、克制、无夸张效果。

图表文字：
- RSTM state trajectory
- S(t)
- Turn
- Initial state: -0.25
- Level 3: Concerned / Downcast

## 6. 7-Level Affective-Interaction Style 风格条

用途：45-60s  

提示词：
> 横向七级情绪与互动风格条，从 Level 1 到 Level 7，颜色从偏冷紧张到中性再到温和积极。Level 3 被高亮，标签为 Concerned / Downcast。整体像医学教育研究图，不像娱乐游戏界面。16:9，可用于动画分镜。

级别标签：
- Level 1 Agitated / Irritated
- Level 2 Anxious / Worried
- Level 3 Concerned / Downcast
- Level 4 Neutral
- Level 5 Mildly Positive / Encouraging
- Level 6 Cooperative / Engaged
- Level 7 Trusting / Reassured

## 7. 训练回看日志界面

用途：60-75s  

提示词：
> RSTM-SP 训练回看界面，三栏布局：Transcript、CPAS score、RSTM trajectory。Transcript 显示完整文字对话；CPAS 显示原始输出和简短评分理由；RSTM trajectory 显示简短状态变化。明确显示 Text-only log 和 Audio retained: No。界面专业、清晰，适合医学教育研究项目展示。

示例界面文本：
- Transcript
- CPAS raw output
- Brief rationale
- RSTM trajectory
- Text-only log
- Audio retained: No

## 8. 结尾画面

用途：75-90s  

提示词：
> 结尾品牌画面，RSTM-SP 产品名居中，背景为抽象诊室轮廓、对话气泡、关系状态曲线和医学教育图标。整体温和、专业、可信。画面底部留出项目团队和联系方式占位。16:9。

屏幕文字：
- RSTM-SP
- 可重复的沟通练习
- 可观察的关系状态变化
- 医学教育研究项目
- 了解更多：项目团队 / 联系方式

## 颜色与字体建议

- 主色：深蓝绿色 `#1F6F78`
- 辅色：浅青色 `#E7F4F3`
- 强调色：暖橙色 `#D99058`
- 文本色：深灰 `#243033`
- 背景：近白 `#F7FAFA`
- 字体风格：清晰、现代、医学教育风格；中文建议使用思源黑体、苹方或等效无衬线字体。

## 不应生成的元素

- 真实患者面部或真实学习者影像。
- 真实医院 logo 或真实机构标识。
- API key、账号、电话号码等敏感信息。
- 夸张商业广告动效。
- 暗示保留音频或展示真实音频波形存档。
- “替代标准化病人”或“已完全临床验证”的文字。
